# Stronger sparsity with GIM

Fresh 5,000-step run, changing only p_end from 0.5 to 0.25 across all 24 matrices.
Uses the baseline GIM run's stored TrainConfig (8,700-step schedule horizon),
initialization seed, data order, reference sample, component counts, precision,
projection, optimizer, epsilon, and LR schedule. It stops at 5,000 updates.

The actual p at update 5,000 is approximately 0.461 versus the control's 0.641.
Neither run has yet reached its terminal p. The post-projection fixed-sum
constraint is unchanged. No auxiliary loss or mask training is added.
The global sparsity coefficient is not swept: sparsity is the sole loss and
Adam mostly cancels a fixed global multiplier through its moment normalization.

The existing GIM .5 checkpoint supplies the control without retraining it.
An explicit configuration comparison allows only p_end to differ. Checkpoints
are immutable every 1,000 updates and at any handled early stop. KLKeep runs
at 5,000 using native GIM ranking on the same 65,536 held-out positions; the
plot includes VPD at 5,000 as a reference. Full checkpoints and evaluation
results are backed up to R2 by a separate afterany CPU job.
