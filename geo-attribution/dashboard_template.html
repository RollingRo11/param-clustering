Grader calibration

The same 80 components, graded by two independent human graders and by the model. Same shape, different strictness — read the model's number as a floor.

The model was recalibrated once mid-run: a first pass graded 22% mono because it penalized narrow families (“surname subword continuations”) for having varying surface tokens — which is generalization, not incoherence.
